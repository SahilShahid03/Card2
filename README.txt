SHARIQ & EENARA — WEDDING INVITATION
=====================================

GitHub Pages-ready multi-page wedding invitation.

Pages:
- index.html  : Home
- story.html  : Our Invitation
- event.html  : Pithi details + countdown + Google Maps
- duas.html   : Duas & Blessings
- rsvp.html   : RSVP / family contact numbers

Assets:
- assets/couple.jpg : uploaded couple photograph

Music:
The Play Music button loads the YouTube video ID o0NqZALXMYE using the YouTube IFrame API.
Browsers normally block autoplay with sound, so visitors need to tap Play Music once.
Because this is a multi-page static site, music playback may need to be started again after navigating to a new page.

Countdown:
The countdown is currently set to 2026-10-30 00:00:00 Pakistan Standard Time (UTC+5), as no exact Pithi start time was provided.
To change it, edit the `target` line in script.js.

Google Maps:
The Pithi page uses a Google Maps search link for 5 Star Ballroom - Pearl, North Nazimabad, Karachi.

GitHub Pages:
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository's Pages settings.
